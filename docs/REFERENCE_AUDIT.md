## Interaction reports reviewed

- AutoBalance reports include overlap with another scaling mod, a transport summon respawn failure and core API drift. These support testing separate module combinations and restricting HP and summon paths. [Overlap report](https://github.com/azerothcore/mod-autobalance/issues/225), [summon report](https://github.com/azerothcore/mod-autobalance/issues/222), [API report](https://github.com/azerothcore/mod-autobalance/issues/220)
- CoA Content Scaling has an open report about instance scaling. The fork's sampled issues also include quest and combat-state behavior. Both remain architectural references. [CoA Content Scaling report](https://github.com/Corfirean/mod-coa-content-scaling/issues/12), [CoA core combat-state report](https://github.com/Conquest-of-AzerothCore/azerothcore-wotlk-coa/issues/13286)
- Zone Difficulty describes itself upstream as a companion to Progression System. Its local source uses its own zone/phase tables, mythic state, player settings and scripts. Those contracts and companion-oriented SQL were left out. The sampled issues include totem healing and encounter effects. Progression System's sampled vendor and phase behavior illustrates why this module leaves release-stage gating native. [Zone Difficulty repository](https://github.com/azerothcore/mod-zone-difficulty), [totem report](https://github.com/azerothcore/mod-zone-difficulty/issues/61), [phase report](https://github.com/azerothcore/mod-progression-system/issues/482)
- Dynamic XP has an open fractional-factor request. Zone Scaling has a duplicate XP report for its optional core patch. This module uses one source-specific native award callback with bounded rounding. [Dynamic XP report](https://github.com/azerothcore/mod-dynamic-xp/issues/9), [Zone Scaling report](https://github.com/firstoni-dev/mod-zone-scaling/issues/3)
- Solocraft has an online group-count request and an ICC vehicle interaction report. Playerbots' sampled issue involved spell listing. Native group membership and ownership are used without importing either system. [Group report](https://github.com/azerothcore/mod-solocraft/issues/58), [vehicle report](https://github.com/azerothcore/mod-solocraft/issues/66), [Playerbots report](https://github.com/mod-playerbots/mod-playerbots/issues/3065)
- The sampled issue listings returned no open issue entries for Character Scale, Global Scaling, Ilvl Scaling or Individual Rates. Open World Difficulty returned 404 for both its project page and issue endpoint.
