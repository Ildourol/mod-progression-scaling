# Source-to-feature matrix

AzerothCore Playerbot core and local runtime source HEAD: `be923cbc45c3f1fab657f91d51fda999f6b81cc5`.
AutoBalance: `1d707cb61a0962ab01e4123681e2d3b66cc558a2`.
Playerbots: `63a27bf038a2215dc96d82b6a4b5027d4e8e9273`.
Headers are under `src/server/game/Scripting/ScriptDefines`. See [reference audit](REFERENCE_AUDIT.md) for commits and license evidence.

| Feature | Exact public callback | Native caller and stage | Alternative and decision |
|---|---|---|---|
| Weapon swings | `UnitScript::ModifyMeleeDamage(Unit*, Unit*, uint32&)` | `Unit::CalculateMeleeDamage`, per damage-school component before armor, outcome and absorb | AutoBalance and Zone Difficulty use this stage. Apply once per native component. Hook lacks attack type. |
| Direct spell, special and weapon spell | `UnitScript::ModifySpellDamageTaken(Unit*, Unit*, int32&, SpellInfo const*)` | `Unit::CalculateSpellDamageTaken`, before its own armor, crit, block and absorb | AutoBalance, CoA and Zone Difficulty use this stage. Restrict to ordinary damage effects. Hit source lacks a reflection flag. |
| Periodic damage or heal | `UnitScript::ModifyPeriodicDamageAurasTick(Unit*, Unit*, uint32&, SpellInfo const*)` | `AuraEffect::HandlePeriodicDamageAurasTick`, `HandlePeriodicHealthLeechAuraTick` and `HandlePeriodicHealAurasTick`. DoT before mitigation, HoT after crit before absorb. | AutoBalance uses this mixed callback. Identify pure ordinary periodic damage or healing. Ambiguous effects stay neutral. |
| Direct healing | `UnitScript::ModifyHealReceived(Unit*, Unit*, uint32&, SpellInfo const*)` | `Spell::DoAllEffectOnTarget` via `Unit::HealBySpell`, after crit and before heal absorb. Core sends healer first for direct and second for periodic. | Restrict to direct-only spell definitions. `Unit::DealHeal` emits OnHeal after committing HP, too late. |
| Reflection and proc safety | Same restricted spell stages | `Spell.cpp` handles reflection and triggers upstream. Raw `Unit::DealDamage` also receives environmental/redirected/scripted damage. | Reject the catch-all. Core does not export trigger origin to these callbacks. Self-damage and explicitly excluded IDs bypass. |
| Health and rank | `AllCreatureScript::OnCreatureSelectLevel(CreatureTemplate const*, Creature*)` | `Creature::SelectLevel` constructs fresh max/create HP and base stat. `Creature::UpdateMaxHealth` later reads the base stat. | Global Scaling snapshots/restores several stats. Use freshly generated health at this boundary, with guards. AutoBalance owns instance stats by default. |
| Pet ownership | Same output callbacks, using native `GetAffectingPlayer` and direct temporary-summon player GUID | Per event; owner resolves using current GUID state | AutoBalance skips player-owned units in ordinary hostile damage; Playerbots maintain AI separately. No raw owner pointer stored. Pet stat inheritance is a separate lifecycle. |
| XP rates | `PlayerScript::OnPlayerGiveXP(Player*, uint32&, Unit*, uint8)` | KillRewarder, PlayerQuest and exploration call sites before final award; native XP lock and bonus logic remain | Dynamic XP ignores source; Individual Rates branches on it. Use native source and world profile to avoid AutoBalance XP interaction. |
| Reputation | `PlayerScript::OnPlayerGiveReputation(Player*, int32, float&, ReputationSource)` | `Player::RewardReputation`, after the native amount calculation and before `ReputationMgr::ModifyReputation` | Individual Rates applies per-source rules. This implementation uses a positive-only outdoor faction allowlist. |
| Profession steps | `PlayerScript::OnPlayerUpdateGatheringSkill(Player*, uint32, uint32, uint32, uint32, uint32, uint32&)` and `OnPlayerUpdateCraftingSkill(Player*, SkillLineAbilityEntry const*, uint32, uint32&)` | `Player::UpdateGatherSkill` / `UpdateCraftSkill` before `UpdateSkillPro`; native award chance and caps still apply | Individual Rates separates reward families. Use explicit profession DBC categories and bound the steps. Fishing has a separate stage. |
| Profiles and exclusions | Same combat callbacks & map/zone/area metadata | Read actor context at dispatch | Zone Difficulty and Zone Scaling use narrower zones; CoA and Global Scaling organize content tiers. Use deterministic factor replacement and final spell exclusions. |
| Reload | `WorldScript::OnAfterConfigLoad(bool)` | World config lifecycle and native reload | Publish one snapshot. Keep HP on native regeneration boundary. |
| Diagnostics | `CommandScript::GetCommands() const` | Native GM command dispatch | Read-only curves, context and gear metrics. |
| Gear, solo compensation | `Player::GetItemByPos`, `GetGroup` and existing output hooks | Diagnostics on demand; group identity only for solo opt-in | Ilvl Scaling drives damage by gear. Solocraft grants instance buffs. Adopt neither mutation. |
| Appearance, armor, tempo, resources, threat, loot | No single sufficiently isolated boundary identified | Object scale, native stat updates, combat timers and core reward state have additional consumers | Character Scale writes object scale. CoA, AutoBalance and Zone Scaling customize core-adjacent stats. Defer these effects. Open World Difficulty checkout unavailable. |

## Reference implementation comparisons

| Reference source / symbol | Inputs, mutation and lifecycle | Module decision |
|---|---|---|
| `mod-autobalance/src/ABUnitScript.cpp`, `_Modify_Damage_Healing`; `ABAllCreatureScript.cpp`, `OnCreatureSelectLevel` | Runtime staged amounts are recomputed from map and per-creature state, while stat selection and reset paths change instance unit health and mana. The magnitude callbacks receive a reference to the running amount. | Compose only on audited output stages, keep default instance HP protected, leave group calculations with AutoBalance. |
| `mod-global-scaling/src/GlobalScaling.cpp`, `OnCreatureAddWorld`, `OnCreatureRemoveWorld`, `OnUnitEnterCombat`, `ModifySpellDamageTaken` | Captures and restores original creature values and may update stale state on combat entry. Its spell path resolves an attacker, target and spell against live policies. | Use native health generation once, without a live-creature cache or regeneration on combat entry. Use native ownership and actual level. |
| `mod-coa-content-scaling/src/CoAContentScaling.cpp`, `RecalculateEncounterCombatStats`, `coa_content_scaling_creature`, `coa_content_scaling_unit` | Receives a boss and encounter snapshot and adjusts current combat stats. The source tree includes fork and patch-specific content assumptions. CoA core ships custom scripts and metadata including `modules/mod-manastorm-endless`. | Use a simple bounded curve and non-mutating TTK projection. Keep live encounter state and authored content native. |
| `mod-zone-difficulty/src/mod_zone_difficulty_scripts.cpp`, `ModifyHealReceived`, `ModifySpellDamageTaken`, `ModifyMeleeDamage`; `mod_zone_difficulty_handler.cpp` | Iterates map/phase policies, spell exceptions and mythic instance state from DB tables. The script can adjust different output families and integrates with its own mode and reward data. | Use independent category scope, property-specific config lookup and exclusions. No dependency on its DB, progression companion, phase gating, or difficulty NPCs. |
| `mod-zone-scaling/src/ZoneScalingCreature.cpp`, `OnCreatureSelectLevel`; `ZoneScalingCombat.cpp`, `ModifySpellDamageTaken`; `ZoneScalingRewards.cpp`, `OnPlayerGiveXP` | Zone and viewer policies inform stat/combat/reward outcomes. Patched paths can synthesize native-facing level or reward context. | Use native levels and optional level-delta output only, with explicit location and entry precedence. Skip viewer level conversion and patch-only paths. |
| `mod-ilvl-scaling/src/IlvlScaling.cpp`, `AverageEquippedItemLevel`, `ComputeScaling`, `GetScalingForPlayer`, `UpgradeCreatureLoot` | Samples gear and group members, checks the fork's `WorldSession::IsBot`, calculates gear-gap factors, caches them and can replace loot entries. | On-demand read-only equipped sample. No gear gap mutations or loot work. The active server's local `IsBot()` alias identifies headless sessions while the two verified clean targets lack the method. |
| `mod-solocraft/src/Solocraft.cpp`, `SetSoloCraftXPModifier`, `DisableXPForSoloCraft`, `SolocraftAnnounce::OnPlayerLogin` and `OnPlayerGiveXP` | Maintains group/instance-dependent buff and XP state, including ownership of a native XP-off flag. | Optional world-only owner output multiplier. Preserve all native flags, stats and group-size behavior. |
| `mod-dynamic-xp/src/dynamicxp.cpp`, `OnPlayerGiveXP`; `mod-individual-rates/src/individual_rates.cpp`, `OnPlayerGiveXP` and `OnPlayerGiveReputation` | Dynamic XP changes the award using a level expression; Individual Rates chooses sources and tracks personal settings. | Cache a world-only bracket per native level, keep XP source discrimination and preserve native caps. Add allowlisted positive reputation and independent profession steps. |
| `mod-character-scale/src/CharacterScale.cpp`, `ScaleApplyEvent::Execute`, `CharacterScaleUnitScript::OnAuraRemove` | Schedules scale writes and reapplies saved scale on aura changes with persistent per-character state. | Leave physical object scale and native transformations alone. Public setters do not isolate cosmetic presentation from gameplay fields. |
| `mod-progression-system/src/cs_progression_module.cpp`, `progression_module_commandscript`; `src/Bracket_*` | Reports native module stages and ships replacement scripts for specific quest, raid and era content. | Keep native world progression. No stage locks or content mutations. |
